# Idea rubric (/60)

Score each idea 1–10 on six dimensions. 5 is an ordinary hackathon entry; 8+ is rare and needs a reason you
can point to in the card. Score what the card describes, not what it might become.

| Dimension | Asks | 3 | 6 | 9 |
|---|---|---|---|---|
| **Novelty** | Is the problem framing *and* the technique new for this domain? | A known app with a new skin | A fresh framing on a familiar technique | Both framing and technique rarely seen |
| **Feasibility** | Can the stated team build the core in the time, with the listed data? | Core depends on data or skills they don't have | Core is buildable; one risky part with a fallback | Core is small, data is listed, fallbacks named |
| **Scalability** | Does it extend beyond the demo: more places, users, or a business? | One-off demo | Clear path to other areas or users | Many users or partners with little extra work |
| **Impact** | Will a real user change a real decision because of it? (potential × adoption) | Nice to know; nobody acts | A clear user acts sometimes | A frequent, costly decision changes |
| **Demo-ability** | Can it be shown working, live and memorably, in about 3 minutes? | Slides or a static chart | A working flow with one clear moment | The audience takes part and sees the payoff |
| **Domain fit** | Does it use what is special about this event's data and theme? | Could run on any dataset | Uses the event data meaningfully | Only possible with this event's data |

## Calibration rules

1. **Novelty cap.** If the core technique is common elsewhere (matching, clustering, percentile comparison,
   recommendation), Novelty is at most 7 however clever the framing. 8+ needs both a new framing and a new technique.
2. **Feasibility counts the core only.** Optional extras don't add or subtract. Deduct for data the event context
   does not list, and for build effort that will not fit the time.
3. **Impact includes adoption.** Ask whether the user would actually use it at the moment of decision, and whether
   anything stops them (trust, habit, a two-sided market, cost).
4. **Judge the idea, not the prose.** Length, polish, confident wording and self-assessment in the card earn nothing.
5. **Use the range.** If every idea lands between 6 and 8 on a dimension, re-read and separate them.

Total = sum of the six (/60). Rough guide: under 36 weak, 36–44 solid, 45–50 strong, over 50 exceptional.
